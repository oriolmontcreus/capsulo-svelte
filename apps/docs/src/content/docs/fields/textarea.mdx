---
title: Textarea
description: A multi-line text input component for capturing longer user input.
---

The `Textarea` field captures multi-line text such as descriptions, comments or longer content. It grows with its content by default, and supports a character limit, translations and global variables.

## Usage

```ts
import { Textarea } from 'capsulo/schema';
```

```ts
// [!code word:Textarea]
Textarea('fieldName').label('Field Label');
```

## API

The `Textarea` builder provides a fluent API to configure the field.

<TypeTable
  type={{
    label: {
      description: 'Sets the label of the field. Defaults to the field name.',
      type: 'string',
    },
    description: {
      description: 'Adds a helper description below the field.',
      type: 'string',
    },
    placeholder: {
      description: 'Sets the placeholder text.',
      type: 'string',
    },
    required: {
      description: 'Marks the field as required. Publishing fails while it is empty in the default locale. Pass a function of the other fields\' values to require it only in some cases.',
      type: 'boolean | (values) => boolean',
      default: 'true',
    },
    hidden: {
      description: 'Hides the field and skips its validation. Pass a function of the other fields\' values to hide it only in some cases. See <a href="/docs/conditional-fields/">Conditional fields</a>.',
      type: 'boolean | (values) => boolean',
      default: 'true',
    },
    defaultValue: {
      description: 'Sets the initial value of the field. It can include global variables, like <code>{{siteName}}</code>.',
      type: 'string',
    },
    rows: {
      description: 'Sets the visible height in rows. With <code>autoresize</code> on, it is the minimum height.',
      type: 'number',
      default: '3',
    },
    autoresize: {
      description: 'Grows the field with its content. Turn it off for a fixed height that scrolls.',
      type: 'boolean',
      default: 'true',
    },
    minLength: {
      description: 'The fewest characters allowed.',
      type: 'number',
    },
    maxLength: {
      description: 'Sets the maximum number of characters. Longer input is cut at the limit.',
      type: 'number',
    },
    regex: {
      description: 'A pattern the whole text must match. Text with a global variable skips the check.',
      type: 'string | RegExp',
    },
    minRows: {
      description: 'The minimum height in rows while it grows with its content. Overrides <code>rows</code>.',
      type: 'number',
    },
    maxRows: {
      description: 'The maximum height in rows; longer text scrolls inside the field.',
      type: 'number',
    },
    resize: {
      description: 'Lets editors drag the field\'s size. Works best with <code>autoresize(false)</code>, since auto-resizing resets the height as they type.',
      type: '"none" | "vertical" | "horizontal" | "both"',
      default: '"none"',
    },
    prefix: {
      description: 'Text or an icon component shown inside the field, before the text.',
      type: 'string | Component',
    },
    suffix: {
      description: 'Text or an icon component shown inside the field, after the text.',
      type: 'string | Component',
    },
    translatable: {
      description: 'Stores a value per locale instead of one shared value.',
      type: 'boolean',
      default: 'true',
    },
  }}
/>

## Value

Your component gets the plain text as a `string` in the current locale.
