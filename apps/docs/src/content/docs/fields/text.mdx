---
title: Text
description: A fundamental component for capturing single-line text.
---

The `Text` field captures single-line text such as titles, names, emails or links. It supports placeholders, validation (formats like email, URL or a pattern, and number ranges), translations and global variables: type `{{` to insert one.

## Usage

```ts
import { Text } from 'capsulo/schema';
```

```ts
// [!code word:Text]
Text('fieldName').label('Field Label');
```

Format rules (`minLength`, `regex`, `type`, `min`…) check every language that has a value, and block committing until they pass. Values that contain a global variable skip the format checks, because the variable is only replaced on the site.

## Value

Your component gets a `string` in the current locale. A `required()` field is typed `string`; otherwise it's `string | undefined`.

With `type("number")` it gets a `number`, or `null` while the field is empty: `number` when the field is `required()`, otherwise `number | null | undefined`.
