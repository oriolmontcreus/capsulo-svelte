---
title: Select
description: A versatile dropdown component for selecting from predefined options.
---

The `Select` field provides a dropdown for choosing from a list of options. It has two modes: a standard select and a searchable combobox. It also supports multiple selection, grouped options, multi-column layouts and an internal links mode for picking pages of your site.

## Usage

```ts
import { Select } from '$lib/form-builder/fields/SelectField/select-field.builder';
```

```ts
// [!code word:Select]
Select('fieldName')
  .label('Field Label')
  .options([
    { label: 'Option 1', value: 'opt1' },
    { label: 'Option 2', value: 'opt2' },
  ]);
```

## Value

Your component gets the selected option's `value` as a `string`, or a `string[]` with `multiple()`. A select has one value for every locale.
