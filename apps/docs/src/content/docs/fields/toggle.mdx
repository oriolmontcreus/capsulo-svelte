---
title: Toggle
description: A switch component for capturing boolean values.
---

The `Toggle` field captures a boolean value with an on/off switch. It's ideal for settings, preferences and showing or hiding parts of a component.

## Usage

```ts
import { Toggle } from '$lib/form-builder/fields/ToggleField/toggle-field.builder';
```

```ts
// [!code word:Toggle]
Toggle('fieldName').label('Field Label');
```

## API

The `Toggle` builder provides a fluent API to configure the field.

<TypeTable
  type={{
    label: {
      description: 'Sets the label of the field. Defaults to the field name.',
      type: 'string',
    },
    description: {
      description: 'Adds a helper description below the field.',
      type: 'string',
    },
    required: {
      description: 'The toggle must be on to publish, like an "accept the terms" checkbox.',
      type: 'boolean',
      default: 'true',
    },
    defaultValue: {
      description: 'Sets the initial value of the field.',
      type: 'boolean',
      default: 'false',
    },
  }}
/>

## Value

Your component gets a `boolean`. A toggle has one value for every locale.
