## What is Capsulo?

Capsulo is a **CMS framework** <span class="text-fd-muted-foreground text-sm">(also known as a [CMF](https://en.wikipedia.org/wiki/Content_management_framework))</span> that lets you define content structures as code and manage them through a beautiful interface. Built for developers who want full control without sacrificing ease of use.

A Capsulo project is an [Astro](https://astro.build/) site with its CMS built in. You build components with Svelte (or any framework Astro supports), describe their editable fields with a schema, and your client edits them at `/admin`.

## Quick start

<Steps>

<Step>

### Create a project

Capsulo needs Node.js 22.12 or newer. Create a new site and start it:

```bash
npm create capsulo@latest my-site
cd my-site
pnpm dev
```

The site runs on `http://localhost:4321` and the CMS on `http://localhost:4321/admin`. You don't need any account or `.env` file to develop: `pnpm dev` creates a local database and signs you in to `/admin` as a local "Developer" user.

</Step>

<Step>

### Define your schema

Each capsule (a content component) describes its editable fields with a schema, written with the Fluent API:

```ts
// src/components/capsules/Hero/hero.schema.ts
import { createSchema } from '$lib/form-builder/core/create-schema';
import { Text } from '$lib/form-builder/fields/TextField/text-field.builder';
import { Textarea } from '$lib/form-builder/fields/TextareaField/textarea-field.builder';

export const heroSchema = createSchema({
  name: 'Hero',
  key: 'hero',
  fields: [
    Text('title').label('Hero title').required().translatable().defaultValue('Welcome'),
    Textarea('subtitle').label('Subtitle').rows(3).translatable(),
  ],
});
```

</Step>

<Step>

### Use it in your component

Read the published values with `getCmsData`. The `HeroData` type is generated from the schema for you:

```svelte
<!-- src/components/capsules/Hero/Hero.svelte -->
<script lang="ts">
  import { getCmsData } from '$lib/cms/get-cms-data';
  import { heroSchema } from './hero.schema';
  import type { HeroData } from './hero.schema.d';

  let { instanceId }: { instanceId: string } = $props();

  const data = $derived(getCmsData<HeroData & Record<string, unknown>>(instanceId, heroSchema));
</script>

<section>
  <h1>{data.title}</h1>
  <p>{data.subtitle}</p>
</section>
```

</Step>

<Step>

### Edit in the CMS

Add the capsule to a page and open `/admin`. Capsulo detects it on that page and shows an auto-generated form for it. No code required for your client!

</Step>

<Step>

### Deploy

When you're ready, deploy to your own Cloudflare account:

```bash
npx capsulo deploy
```

It sets up the database and the upload storage, deploys the site to `https://<name>.<account>.workers.dev` and creates the first CMS user for your client.

</Step>

</Steps>
